=== Mini NPU Simulator ===

[모드 선택]
1. 사용자 입력 (3x3)
2. data.json 분석
3. 패턴 생성기 + 최적화 비교 (보너스)
선택: 3

#----------------------------------------
# [1] 크기 입력
#----------------------------------------
생성할 크기 N을 공백으로 구분해 입력하세요 (3~200, 빈 줄 = 기본값 3 5 13 25 50 100)
크기: 2 a
  입력 형식 오류: 크기 2은(는) 3~200 범위여야 합니다. → 다시 입력하세요.
크기: 7 8

#----------------------------------------
# [2] 패턴 생성
#----------------------------------------
✓ 7×7 생성 완료 — Cross 칸 13개, X 칸 13개
✓ 8×8 생성 완료 — Cross 칸 28개 (짝수 N: 가운데 2줄), X 칸 16개

#----------------------------------------
# [3] 생성 패턴 판정 검증 (입력과 필터 모두 생성 패턴)
#----------------------------------------
7×7 Cross 입력   Cross 점수    13 | X 점수     1 | 판정 Cross     | PASS
7×7 X 입력       Cross 점수     1 | X 점수    13 | 판정 X         | PASS
8×8 Cross 입력   Cross 점수    28 | X 점수     4 | 판정 Cross     | PASS
8×8 X 입력       Cross 점수     4 | X 점수    16 | 판정 X         | PASS
→ 4개 중 4개 PASS

#----------------------------------------
# [4] 성능 분석 (평균/10회 · 입력 = 생성 X 패턴, 필터 = 생성 Cross 패턴)
#----------------------------------------
크기         평균 시간(ms)   연산 횟수(N²)     MAC 1회당(ns)
------------------------------------------------------------

8×8                 0.0026              64              40.9
(각 크기별 MAC 함수 호출 구간만 10회 측정한 평균, 워밍업 1회 제외)

[최적화 비교: 2차원 배열 → 1차원 배열(길이 N²)]
크기           2D 전(ms)     1D 후(ms)   속도 비율   측정당 호출   점수 일치
----------------------------------------------------------------------------

8×8              0.00277       0.00232       1.19x          1024           ✓
(MAC 1회당 평균 시간 · 같은 입력으로 2D/1D를 10회씩 번갈아 측정, 1회 측정 = '측정당 호출'만큼 연속 실행)
(속도 비율 = 2D 시간 ÷ 1D 시간 → 1보다 크면 1D가 빠름 · 점수 일치 = 두 방식의 MAC 결과가 완전히 같은지)
