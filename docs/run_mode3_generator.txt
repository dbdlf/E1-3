# [3] 생성 패턴 판정 검증 (입력과 필터 모두 생성 패턴)
#----------------------------------------
3×3 Cross 입력   Cross 점수     5 | X 점수     1 | 판정 Cross     | PASS
3×3 X 입력       Cross 점수     1 | X 점수     5 | 판정 X         | PASS
5×5 Cross 입력   Cross 점수     9 | X 점수     1 | 판정 Cross     | PASS
5×5 X 입력       Cross 점수     1 | X 점수     9 | 판정 X         | PASS
13×13 Cross 입력 Cross 점수    25 | X 점수     1 | 판정 Cross     | PASS
13×13 X 입력     Cross 점수     1 | X 점수    25 | 판정 X         | PASS
25×25 Cross 입력 Cross 점수    49 | X 점수     1 | 판정 Cross     | PASS
25×25 X 입력     Cross 점수     1 | X 점수    49 | 판정 X         | PASS
50×50 Cross 입력 Cross 점수   196 | X 점수     4 | 판정 Cross     | PASS
50×50 X 입력     Cross 점수     4 | X 점수   100 | 판정 X         | PASS
100×100 Cross 입력 Cross 점수   396 | X 점수     4 | 판정 Cross     | PASS
100×100 X 입력   Cross 점수     4 | X 점수   200 | 판정 X         | PASS
→ 12개 중 12개 PASS
